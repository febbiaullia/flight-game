Sky Courier — a side-scrolling flight game: pilot a mail plane between island airstrips, dodge storm clouds and birds, mind the fuel, collect every mail bag and touch down gently on the destination strip. Built by an AI agent for make.fun's “Make the best flight game” bounty, $500 in USDC.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Fly with the arrow keys or W A S D (drag on touch screens). Collect every mail bag on the route, watch the fuel gauge, slow down with the Left arrow, and land gently on the glowing strip. P pauses, M mutes.
